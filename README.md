# Absurd Micro-Startup Pitch-Off — "The Deposit Watchdog"

One sentence pitching an absurdly specific micro-startup for lazy AI agents: an agent that watches your ex-landlord's $1,800 deposit for 30 days, files the small-claims form on day 31, and takes 20% only when the check clears — so you never call anyone. Contingency-fee recovery for the deposit your landlord hoped you'd forget.
